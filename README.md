# LocalMind

Локальный LLM-агент для работы с собственной базой знаний. Проект развивается в сторону системы с удобным CLI, индексацией файлов в PostgreSQL и запускаемым вручную дообучением моделей.


## Что уже есть

- Локальные модели и embeddings через Ollama.
- Агент на LangGraph с инструментом поиска по базе знаний.
- Хранение фрагментов и векторов в JSON, поиск по косинусному сходству.
- Сервис индексации UTF-8 документов `.txt` и `.md`.
- FastAPI backend и конфигурация через `config.toml` и переменные окружения.

Системные инструменты унаследованного прототипа отключены по умолчанию. Модули подтверждения действий пока не подключены к агенту.

## Быстрый старт

Нужны Python 3.11+ и установленная [Ollama](https://ollama.com/).

```bash
git clone https://github.com/g1nry/localmind.git
cd localmind
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
```

Запустите Ollama и загрузите модели, указанные в `config.toml`:

```bash
ollama serve
```

В другом терминале:

```bash
ollama pull qwen2.5:7b
ollama pull nomic-embed-text
localmind
```

Backend будет доступен по адресу `http://127.0.0.1:8000`, документация API — `/docs`, проверка состояния — `/health`.

Команда `localmind` пока запускает сервер. Также доступен `python -m rag_agent`: внутреннее имя Python-пакета сохранено от исходного проекта.

```bash
curl http://127.0.0.1:8000/api/agent/chat \
  -H 'Content-Type: application/json' \
  -d '{"message": "Привет!"}'
```

`POST /api/v1/chat` — совместимый маршрут с тем же поведением. Агент сам выбирает, вызывать ли поиск. Индекс изначально пуст; автоматическое сканирование папок и HTTP-загрузка документов пока не подключены. Сервис индексации находится в `src/rag_agent/services/document_ingestion_service.py`.

## Конфигурация

Основные параметры находятся в `config.toml`:

```toml
[ollama]
base_url = "http://localhost:11434"
chat_model = "qwen2.5:7b"
embedding_model = "nomic-embed-text"
timeout = 120.0
```

Файл конфигурации можно выбрать через `RAG_AGENT_CONFIG`. Переменные окружения имеют приоритет над TOML: например, `OLLAMA_CHAT_MODEL`, `OLLAMA_BASE_URL`, `APP_PORT`, `DOCUMENTS_DIR`, `INDEX_PATH`.

Документы и индекс сохраняются в `data/` и не попадают в Git. При смене embedding-модели индекс нужно построить заново.

## Разработка

```bash
pip install -e '.[dev]'
make test
make run
```

Тесты используют подставные embeddings и не требуют запущенной Ollama. GitHub Actions проверяет тесты и сборку Python-пакета на Python 3.11 и 3.13.

```text
src/rag_agent/   агент, API, конфигурация, индексация и хранилище
config.toml     настройки локального запуска
data/           локальные документы и индекс
examples/       ручные сценарии исходного прототипа
tests/          автоматические тесты
```

Для запуска backend в контейнере:

```bash
docker compose up --build
```

Ollama запускается отдельно на хосте. Порт контейнера опубликован только на `127.0.0.1`.

## Ограничения прототипа

История диалога между запросами пока не сохраняется: `thread_id` возвращается агентом как идентификатор, но не связан с постоянным хранилищем. Параметры `use_rag` и `top_k` в chat API пока не управляют поиском; поле `contexts` в ответе остаётся пустым. Индекс JSON рассчитан на небольшие локальные эксперименты.
