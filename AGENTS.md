# Работа с репозиторием

- Пишите сообщения коммитов, заголовки и описания pull request на русском языке.
- Разделяйте изменения на небольшие коммиты по смыслу; не объединяйте весь этап в один коммит.
- Сохраняйте минимальный объём изменений в рамках текущей задачи.
- Не добавляйте пользовательские документы, индексы, модели и секреты в Git.
- В README разделяйте работающие возможности и планы.
- Перед отправкой изменений запускайте `python -m pytest` и проверяйте сборку пакета: `python -m build`.
